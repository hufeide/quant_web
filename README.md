# QuantLab Pro · 全流程投研平台功能原型

一个**纯前端、零依赖、可离线打开**的投资研究平台界面原型，用于直观感受一个完整投研平台"应该长什么样、有哪些功能"。

- **2,756 项功能**（366 个功能面板 + 2,390 项子功能），覆盖 **42 个业务模块**
- 结构为三级：**模块 → 功能面板（卡片 + 图表 + 说明）→ 子功能（可独立排期的细粒度功能点 WBS）**
- **只做界面与功能说明，不实现算法**：所有图表为种子随机数的示意数据；每项功能都配「功能说明 + 核心指标 + 数据依赖 + 算法实现要点 + 输出与下游 + 关联功能」，子功能可直接作为开发任务拆分依据
- 网页与 `FUNCTIONS.md`（13,900 行）共用同一份功能注册表生成，永不脱节

## 快速开始

```bash
# 直接双击打开（file:// 可完整运行，无需服务器、无 CDN、无网络请求）
xdg-open index.html
# 或本地服务
python3 -m http.server 8000
```

## 三级功能结构

```js
F({                       // 一级：模块（41 个）
  id: 'FAC-08', m: 'factor', w: 6, tags: ['核心'],
  desc: '多因子模型与组合优化 …',        // 卡片一句话
  spec: '完整功能说明 …',                // 抽屉详情
  metrics: ['预期超额', '跟踪误差', …],  // 核心指标
  data: [...], algo: [...], out: [...], links: [...],
  viz: () => V.bar(...),                 // 示意图表
  subs: [                                // 三级：子功能（可独立排期）
    '约束松弛诊断|哪个约束在起作用的分析',
    '整手取整|权重到可交易数量转换'
  ]
});
// 也可在深化文件中用 S('FAC-08', '名称|说明', …) 追加
```

## 开发与校验

```bash
node tools/check.mjs       # 366 面板图表渲染、2756 项功能字段、关联引用完整性
node tools/dom-check.mjs   # 43 个页面 + 全部抽屉在 DOM 桩下渲染
node tools/gen-docs.mjs    # 重新生成 FUNCTIONS.md
```

当前状态：2,756 项功能全部通过；每个面板都有 6-10 项子功能；所有 SVG 坐标在画布内；栅格在任意标签筛选下每行恰好填满 12 列。另有「我的 AI 工作台」：面向个人/基金经理/研究员，可通过搜索与对话把全平台功能搭建为专属技能流。

### 新增一个功能

在 `registry/` 对应文件中 `F({...})` 注册面板，用 `subs: ['名称|说明']` 或 `S('ID', '名称|说明')` 添加子功能，然后：

```bash
node tools/check.mjs && node tools/gen-docs.mjs
```

## 实现路线建议

| 阶段 | 目标 | 范围 |
| --- | --- | --- |
| 一期 数据底座 | 让数据可信 | `DAT-*` 全量 + `PLT-*` 平台工程 + 基础行情财务 |
| 二期 研究能力 | 让研究可复用 | 各资产 P0 面板 + `FAC-01~04` + `KNO-01` + 语义层 |
| 三期 策略组合 | 让结论可执行 | `STR-*`、`PORT-*`、`EXE-*`、`MM-*` |
| 三期-b 智能引擎 | 自主化 | `ANM/RGM/AIP/RSP/FAR/AIC-*` 六大引擎 + `STR-11~17`、`EQ-15~17`、`IND-09/10`、`MAC-11~13`、`KNO-07~10` | 异常雷达与状态引擎先行 |
| 四期 AI 创新 | 让效率倍增 | `AI-*`、`AGT-*`、`AIO-*`（前置：`AI-12`/`AIO-07` 治理） |
| 五期 业务合规 | 覆盖经营 | `WL-*`、`CLI-*`、`RGT-*` |
| 六期 另类资产 | 扩展资产边界 | `PRI/REI/CRY/CRD/INS/SUS/RT/TH-*`（前置：数据许可与合规） |

优先级：P0 核心面板 94 个 / P1 完整性面板 / P2 AI 与创新 93 项（含 AI 标记子功能）。详见 `FUNCTIONS.md` 附录 A~E。

## 说明与边界

- 所有数值均为固定种子伪随机数生成的**示意数据**，无真实行情、无算法实现、无网络请求。
- 涨跌颜色遵循 A 股习惯：**红涨绿跌**。建议窗口宽度 ≥1280px。
