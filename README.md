# QuantLab Pro · 全流程投研平台功能原型

一个**纯前端、零依赖、可离线打开**的投资研究平台界面原型，用于直观感受一个完整投研平台"应该长什么样、有哪些功能"。

- **4,013 项功能**（515 个功能面板 + 3,498 项子功能），覆盖 **60 个业务模块**，含 270 个 AI 融合场景与 18 个可点击 AI 实演案例
- 结构为三级：**模块 → 功能面板（卡片 + 图表 + 说明）→ 子功能（可独立排期的细粒度功能点 WBS）**
- **只做界面与功能说明，不实现算法**：所有图表为种子随机数的示意数据；每项功能都配「功能说明 + 核心指标 + 数据依赖 + 算法实现要点 + 输出与下游 + 关联功能」，子功能可直接作为开发任务拆分依据
- 网页与 `FUNCTIONS.md`（20,673 行）共用同一份功能注册表生成，永不脱节

## 快速开始

```bash
# 直接双击打开（file:// 可完整运行，无需服务器、无 CDN、无网络请求）
xdg-open index.html
# 或本地服务
python3 -m http.server 8000
```

### 先试 AI 实演中心

左侧「AI 实演中心」（`#/m/demo`）提供 18 个**可点击的完整样例**：每个案例首屏就带 2-3 个**可点问法**，点一下即生成完整的样例回答（用户问句 + AI 的过程、图表、结论、下一步），无需自己输入；打开即有预置对话，点击气泡下的推荐问法可继续多轮追问（或自己输入，命中关键词会进入对应分支），走到结尾会出现「回到开头」，右上角可重放。涵盖自然语言取数、个股加仓五模块决策、一句话搭技能流、读文章找机会、全局搜索、自动研究工厂、对话挖因子、财报夜、反事实、大跌陪伴、多空辩论、基金经理晨会、突发事件 10 分钟反应、CPI 解读日、一键生成报告、对话沉淀为团队技能，另有 **22 种图表 × 真实场景的配图库**与 **AI 自动选图**样例（同一份数据问不同问题自动换图并说明理由）。对话中的每个图表都是真实渲染的场景配图（非占位图），数字均为样例脚本，无真实算法。

## 三级功能结构

```js
F({                       // 一级：模块（60 个）
  id: 'FAC-08', m: 'factor', w: 6, tags: ['核心'],
  desc: '多因子模型与组合优化 …',        // 卡片一句话
  spec: '完整功能说明 …',                // 抽屉详情
  metrics: ['预期超额', '跟踪误差', …],  // 核心指标
  data: [...], algo: [...], out: [...], links: [...],
  viz: () => V.bar(...),                 // 示意图表
  subs: [                                // 三级：子功能（可独立排期）
    '约束松弛诊断|哪个约束在起作用的分析',
    '整手取整|权重到可交易数量转换'
  ]
});
// 也可在深化文件中用 S('FAC-08', '名称|说明', …) 追加
```

## 开发与校验

```bash
node tools/check.mjs       # 515 面板渲染、4013 项功能字段、demo 脚本完整性
node tools/dom-check.mjs   # 60 个页面 + 全部抽屉在 DOM 桩下渲染
node tools/gen-docs.mjs    # 重新生成 FUNCTIONS.md
```

当前状态：3,017 项功能全部通过；每个面板都有 6-10 项子功能；所有 SVG 坐标在画布内；栅格在任意标签筛选下每行恰好填满 12 列。投资决策闭环（决策 OS + 组合构建引擎）补齐了"研究→论点→预测→仓位→交易→归因→学习"的中间层。

### 新增一个功能

在 `registry/` 对应文件中 `F({...})` 注册面板，用 `subs: ['名称|说明']` 或 `S('ID', '名称|说明')` 添加子功能，然后：

```bash
node tools/check.mjs && node tools/gen-docs.mjs
```

## 说明与边界

- 所有数值均为固定种子伪随机数生成的**示意数据**，无真实行情、无算法实现、无网络请求。
- 涨跌颜色遵循 A 股习惯：**红涨绿跌**。建议窗口宽度 ≥1280px。
